---
name: Internal-page branding
description: Scope of ChargePoint orange versus the legacy TON green styling.
---

The previous TON green refresh is legacy styling on pages not yet rebranded. New internal pages redesigned from user-provided mockups use ChargePoint orange, like authentication. Keep untouched pages and the dashboard’s existing banner and color treatment unchanged.

**Why:** The user previously requested TON green outside the dashboard, but subsequently chose ChargePoint as the new company. In the internal-page redesign, they explicitly asked to use the company color instead of the reference mockup’s green. The dashboard preservation request has not changed.

**How to apply:** Use ChargePoint orange for newly requested internal-page redesigns, not a global theme change. Do not recolor older screens or the dashboard unless explicitly requested.
