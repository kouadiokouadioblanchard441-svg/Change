---
name: Withdrawal hours
description: Product rule for when users in the RDC can submit withdrawal requests.
---

Site-wide withdrawal requests are open from 09:00 inclusive until 18:00 exclusive in Africa/Kinshasa local time.

**Why:** The user asked for withdrawal hours from 9:00 to 18:00 using RDC time, and the site currently serves only the RDC.

**How to apply:** Keep the admin-configured start/end hours, user-facing schedule, and server-side time check aligned on Kinshasa time.
